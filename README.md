## Projects

  LSP, and Git context. Zero Electron. `Swift` `SwiftUI` `AppKit`

- **Terraform providers** — production-grade providers for
  [3x-ui](https://github.com/batonogov/terraform-provider-threexui),
  [Remnawave](https://github.com/batonogov/terraform-provider-remnawave), and
  [Synology DSM](https://github.com/batonogov/terraform-provider-synology-dsm).
  `Go` `Terraform Plugin Framework`

- **[Xray Health Exporter](https://github.com/batonogov/xray-health-exporter)** —
  Prometheus health checks for Xray-core tunnels, powered by Xray-core embedded
  directly as a library. `Go` `Prometheus`

- **Delivery** — reusable [Helm charts](https://github.com/batonogov/helm-charts)
  and a [Homebrew tap](https://github.com/batonogov/homebrew-tap) that make my
  projects easy to install and operate.
